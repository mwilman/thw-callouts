# THW Einsatzmanagement - Workshop Projekt

Ein interaktives Webprojekt für THW-Schüler (14-18 Jahre) zum Erlernen der Webentwicklung.

## 🚀 Schnellstart

```bash
# Dependencies installieren
npm install

# Entwicklungsserver starten
ng serve

# Im Browser öffnen: http://localhost:4200
```

## 📋 Workshop-Features

- ✅ Einsatzliste anzeigen
- ✅ Neue Einsätze erstellen
- ✅ Einsatzstatus ändern
- ✅ Fahrzeuge und Personal verwalten
- ✅ Live-Statistiken
- ✅ Responsive Design

## 🎯 Lernziele

- HTML Templates verstehen
- TypeScript Grundlagen
- Event-Handling
- Datenmanipulation
- Angular Direktiven
